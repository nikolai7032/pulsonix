1. Назначение и область применения1. Mērķis un pielietojuma joma

Pulsonix — система автоматизированного проектирования электроники (EDA) британской компании WestDev Ltd. В одной среде объединены ввод принципиальной схемы, моделирование (в версии 14 — встроенный симулятор PulsonixSim на базе ngspice), проектирование печатной платы, трёхмерный просмотр и выпуск производственных файлов.Pulsonix ir Lielbritānijas uzņēmuma WestDev Ltd. elektronikas automatizētās projektēšanas (EDA) sistēma. Vienā vidē apvienoti principiālās shēmas ievade, modelēšana (14. versijā — iebūvētais simulators PulsonixSim, kas balstīts uz ngspice), iespiedshēmas plates projektēšana, 3D skats un ražošanas failu sagatavošana.

Руководство описывает рабочий процесс от создания схемы до передачи файлов на производство и содержит справочники горячих клавиш и команд. Оно опирается на официальную документацию Pulsonix 14.0 (онлайн-справка и Users Guide, редакция от 05.01.2026).Rokasgrāmata apraksta darba procesu no shēmas izveides līdz failu nodošanai ražošanai un ietver taustiņu kombināciju un komandu uzziņas. Tā balstās uz oficiālo Pulsonix 14.0 dokumentāciju (tiešsaistes palīdzība un Users Guide, 05.01.2026. redakcija).

2. Интерфейс и базовая навигация2. Interfeiss un pamatnavigācija

2.1. Главное окно2.1. Galvenais logs

Pulsonix работает в многодокументном режиме (MDI): одновременно можно открыть несколько схем, плат, библиотек и технологий. Меню расположены слева направо в порядке этапов проектирования. Основные элементы окна:Pulsonix darbojas vairāku dokumentu režīmā (MDI): vienlaikus var atvērt vairākas shēmas, plates, bibliotēkas un tehnoloģijas. Izvēlnes izvietotas no kreisās uz labo pusi projektēšanas posmu secībā. Loga galvenie elementi:

  • строка меню — её, как и панели инструментов, можно открепить и сделать плавающей;izvēlnes josla — to, tāpat kā rīkjoslas, var atvienot un padarīt peldošu;
  • панели инструментов — состав зависит от типа активного документа (Schematic или PCB) и настраивается в Tools → Customise;rīkjoslas — sastāvs atkarīgs no aktīvā dokumenta veida (Schematic vai PCB) un tiek konfigurēts Tools → Customise;
  • рабочая область документа;dokumenta darba zona;
  • докируемые окна (браузеры) — см. п. 2.3;dokojamie logi (pārlūki) — sk. 2.3. punktu;
  • строка состояния — подсказка о текущем действии, свойства выделенного объекта, координаты X/Y (Abs или Rel), текущая сетка и единицы.statusa josla — padoms par aktuālo darbību, atlasītā objekta īpašības, X/Y koordinātas (Abs vai Rel), aktuālais tīkls un vienības.
Активная строка состоянияAktīva statusa josla

Двойной щелчок по полям строки состояния позволяет менять значения на месте: щелчок по Abs переключает абсолютные/относительные координаты, по Grid — открывает диалог сеток, по единицам — переключает мм ↔ thou. Если команда ведёт себя неожиданно, сначала прочитайте подсказку в строке состояния: там написано, чего ожидает программа.Dubultklikšķis uz statusa joslas laukiem ļauj mainīt vērtības uz vietas: klikšķis uz Abs pārslēdz absolūtās/relatīvās koordinātas, uz Grid — atver tīklu dialogu, uz vienībām — pārslēdz mm ↔ thou. Ja komanda uzvedas neparedzēti, vispirms izlasiet padomu statusa joslā — tur ir rakstīts, ko programma sagaida.

Знаки + или − после координаты в строке состояния означают, что фактическое значение чуть больше или чуть меньше показанного (точность отображения ограничена настройкой Units).Zīmes + vai − pēc koordinātas statusa joslā nozīmē, ka faktiskā vērtība ir nedaudz lielāka vai mazāka par rādīto (attēlošanas precizitāti ierobežo Units iestatījums).

14. Работа с Pulsonix Vault14. Darbs ar Pulsonix Vault

Vault — система управления данными Pulsonix. В простейшем виде это «управляемая библиотека», но в нём можно хранить также проекты и производственные файлы (Gerber, ODB++). Vault контролирует, кто и как изменяет данные, знает связи между элементами и хранит историю ревизий каждого элемента.Vault ir Pulsonix datu pārvaldības sistēma. Vienkāršākajā veidā tā ir «pārvaldīta bibliotēka», bet tajā var glabāt arī projektus un ražošanas failus (Gerber, ODB++). Vault kontrolē, kurš un kā maina datus, zina saites starp elementiem un glabā katra elementa revīziju vēsturi.

Нужен ли VaultVai Vault ir nepieciešams

Vault — платная опция лицензии (проверяется в License Manager). Использовать его не обязательно: можно работать с обычными библиотеками и файлами. Одна галочка в Tools → Options скрывает все команды Vault из интерфейса. Если в фирме уже есть своя система документооборота, Vault обычно не нужен.Vault ir maksas licences opcija (pārbaudāma License Manager). To nav obligāti izmantot: var strādāt ar parastajām bibliotēkām un failiem. Viena atzīme Tools → Options paslēpj visas Vault komandas no interfeisa. Ja uzņēmumam jau ir sava dokumentu aprites sistēma, Vault parasti nav nepieciešams.

14.1. Устройство14.1. Uzbūve

  • Сервер — база данных PostgreSQL (в v14 — версия 14.5) хранит описание элементов, связи, пользователей и журнал.Serveris — PostgreSQL datubāze (v14 — versija 14.5) glabā elementu aprakstus, saites, lietotājus un žurnālu.
  • Папка данных — сами файлы хранятся не в базе, а в общей сетевой папке с правами чтения и записи для всех пользователей Vault (путь в формате UNC: \\сервер\ресурс\папка).Datu mape — faili paši tiek glabāti nevis bāzē, bet kopīgā tīkla mapē ar lasīšanas un rakstīšanas tiesībām visiem Vault lietotājiem (ceļš UNC formātā: \\serveris\resurss\mape).
  • Клиенты — Pulsonix на рабочих местах подключается к базе через ODBC-драйвер PostgreSQL (в v14 — версия 13.0), который ставится вместе с Pulsonix.Klienti — Pulsonix darbstacijās pieslēdzas bāzei ar PostgreSQL ODBC draiveri (v14 — versija 13.0), kas tiek instalēts kopā ar Pulsonix.
  • Для работы с Pulsonix 14 все три компонента должны быть актуальны: ODBC 13.0, PostgreSQL 14.5, база Vault версии 14.0.Darbam ar Pulsonix 14 visām trim komponentēm jābūt aktuālām: ODBC 13.0, PostgreSQL 14.5, Vault bāzes versija 14.0.
ВажноSvarīgi

Никогда не открывайте и не изменяйте файлы в папке данных Vault вручную через Проводник — это может безвозвратно повредить хранилище.Nekad neatveriet un nemainiet failus Vault datu mapē manuāli ar Explorer — tas var neatgriezeniski sabojāt glabātuvi.

Каждый элемент получает уникальный идентификатор IID (Item ID). При каждом сохранении в Vault создаётся новая версия (метка времени), которой присваивается имя ревизии по схеме нумерации. Сочетание IID и версии однозначно указывает конкретное состояние элемента — например, Part знает, какую именно версию посадочного места использует. IID un versijas kombinācija precīzi norāda konkrētu elementa stāvokli — piemēram, Part zina, kuru tieši footprint versiju tas izmanto. Katrai instalācijai ir savs Vault ID, tāpēc dažādu glabātuvju elementi nesajaucas: svešu elementu var ievietot tikai kā jaunu.

Рекомендуемый подход: разработку вести в обычных локальных библиотеках, а в Vault помещать готовые, «опубликованные» элементы.Ieteicamā pieeja: izstrādi veikt parastajās lokālajās bibliotēkās, bet Vault ievietot gatavus, «publicētus» elementus.

19.1. Pulsonix Database Connection (PDC) — подробнее19.1. Pulsonix Database Connection (PDC) — detalizētāk

PDC «подключает» Pulsonix к корпоративной базе данных компонентов для параметрического поиска и последующей вставки нужных элементов в проект, с отслеживанием изменений в базе (по официальному PDC Users Guide).PDC «pieslēdz» Pulsonix korporatīvajai komponentu datubāzei parametriskai meklēšanai un vēlākai nepieciešamo elementu ievietošanai projektā, ar bāzes izmaiņu izsekošanu (pēc oficiālās PDC Users Guide).

  • В качестве источника данных подходит практически любая база, доступная через ODBC — специализированные MRP/CIS-системы, обычные СУБД, а также более простые источники вроде Excel-таблиц или CSV/текстовых файлов.Par datu avotu piemērota praktiski jebkura bāze, kas pieejama ar ODBC — specializētas MRP/CIS sistēmas, parastas DBVS, kā arī vienkāršāki avoti, piemēram, Excel tabulas vai CSV/teksta faili.
  • Если готовой базы ещё нет — PDC включает инструменты, которые помогают создать её из уже имеющихся библиотек Pulsonix как отправную точку.Ja gatavas bāzes vēl nav — PDC ietver rīkus, kas palīdz izveidot to no jau esošajām Pulsonix bibliotēkām kā sākumpunktu.
  • Настройка подключения — Setup → Database Connection (либо кнопка Setup в любом диалоге/панели, связанной с базой): указываются параметры подключения и файл конфигурации (DCC).Pieslēguma konfigurācija — Setup → Database Connection (vai poga Setup jebkurā dialogā/panelī, kas saistīts ar bāzi): norāda pieslēguma parametrus un konfigurācijas failu (DCC).
  • Повседневная работа — через панельIkdienas darbs — ar paneli Database Bar: параметрический поиск по полям базы, сохранение поисковых запросов, вставка найденного компонента в проект.: parametriskā meklēšana pēc bāzes laukiem, meklēšanas pieprasījumu saglabāšana, atrastā komponenta ievietošana projektā.

19.2. Сетевые лицензии (Network Licensing, NLS) — подробнее19.2. Tīkla licences (Network Licensing, NLS) — detalizētāk

Сетевое лицензирование централизует выдачу лицензий через сервер лицензий, защищённый аппаратным ключом; лицензии «берутся» клиентом на время сеанса по схеме «выдал/вернул» (по официальному Network Licensing Installation Guide).Tīkla licencēšana centralizē licenču izsniegšanu ar licenču serveri, aizsargātu ar aparatūras atslēgu; licences klients «paņem» sesijas laikam pēc shēmas «izsniedza/atdeva» (pēc oficiālās Network Licensing Installation Guide).

  • Можно гибко настраивать, каким пользователям и/или машинам доступны какие именно лицензии (например, один человек работает только со схемой, другой — со схемой, платой и автотрассировщиком).Var brīvi konfigurēt, kuriem lietotājiem un/vai datoriem ir pieejamas kuras tieši licences (piemēram, viens cilvēks strādā tikai ar shēmu, otrs — ar shēmu, plati un automātisko trasētāju).
  • Базовые термины:Pamattermini: NLS (Network License Server в целом),(Network License Server kopumā), NLSD (сама служба-«демон», выдающая лицензии),(pats «dēmona» serviss, kas izsniedz licences), NLSM (программа администрирования — Network License Manager),(administrēšanas programma — Network License Manager), NLSL (просмотр журналов — Log Viewer),(žurnālu skatīšana — Log Viewer), Heartbeat (периодический сигнал клиента серверу, подтверждающий, что лицензия всё ещё используется).(periodisks klienta signāls serverim, kas apstiprina, ka licence joprojām tiek izmantota).
  • Порядок установки: сначала отдельный инсталлятор Pulsonix Network License Server Setup (не совпадает с установщиком самого Pulsonix) → настройка и запуск сервера → на клиентских машинах в License Manager указывается имя/адрес сервера и порт.Instalācijas kārtība: vispirms atsevišķs instalators Pulsonix Network License Server Setup (nesakrīt ar pašas Pulsonix instalatoru) → servera konfigurācija un palaišana → klientu datoros License Manager norāda servera nosaukumu/adresi un portu.
  • На одном компьютере не может быть одновременно установлен единственный узловой (node-locked) ключ и сетевой клиент для той же лицензии — это разные схемы распространения лицензий.Vienā datorā nevar vienlaikus būt instalēta node-locked atslēga un tīkla klients tai pašai licencei — tās ir dažādas licenču izplatīšanas shēmas.

20.2. Общий опыт по автотрассировке (не только в Pulsonix)20.2. Vispārēja pieredze ar automātisko trasēšanu (ne tikai Pulsonix)

  • Распространённое мнение среди опытных разработчиков плат: автотрассировщик неплохо справляется с простыми платами (двухслойные, не слишком плотные, преимущественно цифровые), но для плотных, аналоговых или высокоскоростных плат чаще проигрывает аккуратной ручной трассировке — как по итоговой длине дорожек, так и по количеству переходных отверстий.Izplatīts pieredzējušu plašu izstrādātāju uzskats: automātiskais trasētājs labi tiek galā ar vienkāršām platēm (divslāņu, ne pārāk blīvām, galvenokārt digitālām), bet blīvām, analogām vai augstas ātrdarbības platēm biežāk zaudē rūpīgai manuālai trasēšanai — gan pēc trasu kopējā garuma, gan pēc pārejas atveru skaita.
  • Один из пользователей Pulsonix (форумное обсуждение, около 2010-х годов) отмечал, что связка Pulsonix + сторонний автотрассировщикViens no Pulsonix lietotājiem (foruma diskusija, apkārt 2010. gadiem) atzīmēja, ka saikne Pulsonix + trešās puses automātiskais trasētājs Electra (коммерческий, ~$645 на момент того обсуждения) давала почти 100%-ную разводку даже на сложных платах — заметно лучше, чем автотрассировщик, встроенный в Eagle на тот момент. Это не независимо проверенный факт для Вашей версии/платы, а отдельное свидетельство из форума, которое стоит воспринимать как ориентир, а не гарантию.(komerciāls, ~645 USD tās diskusijas laikā) deva gandrīz 100% izlikumu arī sarežģītām platēm — ievērojami labāk nekā tolaik Eagle iebūvētais automātiskais trasētājs. Šis nav neatkarīgi pārbaudīts fakts Jūsu versijai/platei, bet atsevišķs foruma liecinājums, ko vērts uzskatīt par orientieri, nevis garantiju.
  • Практическая рекомендация, которая повторяется почти во всех источниках независимо от конкретной EDA-программы: прежде чем запускать любой автотрассировщик — обязательно должны быть корректно настроены классы цепей, зазоры и правила (Design Rules/Technology, см. главу 8.1), а критичные цепи (питание, земля, высокоскоростные/дифференциальные пары) лучше развести вручную заранее и «запереть» (Lock), чтобы автотрассировщик их не трогал. Автотрассировщик в этом случае используется для оставшейся рутинной массы соединений, а не для платы целиком «одной кнопкой».Praktisks ieteikums, kas atkārtojas gandrīz visos avotos neatkarīgi no konkrētās EDA programmas: pirms jebkura automātiskā trasētāja palaišanas — obligāti jābūt korekti konfigurētām ķēžu klasēm, atstarpumiem un noteikumiem (Design Rules/Technology, sk. 8.1. nodaļu), bet kritiskās ķēdes (barošana, zeme, augstas ātrdarbības/diferenciālie pāri) labāk iztrasēt manuāli iepriekš un «noslēgt» (Lock), lai automātiskais trasētājs tās neskartu. Automātiskais trasētājs šajā gadījumā tiek izmantots atlikušajai rutīnas savienojumu masai, nevis visai platei ar «vienu pogu».
  • После автотрассировки в любом случае нужен ручной проход: визуальная проверка аккуратности (нет ли некрасивых «зигзагов», лишних переходных отверстий, слишком острых углов) и повторный запуск Design Verify/DRC (глава 9.1).Pēc automātiskās trasēšanas jebkurā gadījumā nepieciešams manuāls caurskats: vizuāla rūpības pārbaude (vai nav neglītu «zigzagu», lieku pārejas atveru, pārāk asu leņķu) un atkārtota Design Verify/DRC palaišana (9.1. nodaļa).

20.3. Бесплатные автотрассировщики: что реально есть на рынке20.3. Bezmaksas automātiskie trasētāji: kas tiešām ir tirgū

«Идеального» бесплатного автотрассировщика (в смысле — надёжно дающего 100% разводку профессионального качества без ручной доработки) по общему мнению сообщества не существует ни для одной EDA-программы. Но есть один стабильно рекомендуемый вариант:«Ideāla» bezmaksas automātiskā trasētāja (tādā nozīmē, ka tas droši dod 100% izlikumu profesionālā kvalitātē bez manuālas pabeigšanas) kopienas vispārējā uzskatā nav nevienai EDA programmai. Bet ir viens stabili ieteikts variants:

  • FreeRouting (freerouting.org / github.com/freerouting/freerouting) — открытый (GPL/open source) автотрассировщик на Java, работающий по тому же принципу «импорт/экспорт файла», что и коммерческие Specctra/Electra: рассчитан на любую EDA-программу, которая умеет экспортировать разводку в формат Specctra DSN (.dsn) и импортировать обратно файл сессии (.ses). Исторически наиболее известен в связке с KiCad (там даже есть отдельный плагин, не требующий ручного экспорта), но сам формат DSN универсален.(freerouting.org / github.com/freerouting/freerouting) — atvērtā koda (GPL/open source) automātiskais trasētājs Java valodā, kas darbojas pēc tā paša «faila importa/eksporta» principa, kas komerciālie Specctra/Electra: paredzēts jebkurai EDA programmai, kas spēj eksportēt izlikumu Specctra DSN (.dsn) formātā un importēt atpakaļ sesijas failu (.ses). Vēsturiski visvairāk zināms saiknē ar KiCad (tur ir pat atsevišķs spraudnis, kas neprasa manuālu eksportu), bet pats DSN formāts ir universāls.
  • Опыт пользователей с FreeRouting неоднозначный: для простых 2–4-слойных плат результат обычно приемлемый и доводится до 100% разводки; на сложных платах встречаются как очень good отзывы («довёл до ума после ручной черновой трассировки»), так и отрицательные («не смог развести часть цепей, использовал заметно больше переходных отверстий, чем аккуратная ручная трассировка»). То есть результат сильно зависит от конкретной платы и от того, насколько хорошо расставлены компоненты (placement) до запуска.Lietotāju pieredze ar FreeRouting ir neviendabīga: vienkāršām 2–4 slāņu platēm rezultāts parasti ir pieņemams un tiek novests līdz 100% izlikumam; sarežģītām platēm sastopami gan ļoti labi atsauksmes («novedu līdz galam pēc manuālas rupjās trasēšanas»), gan negatīvas («nespēju iztrasēt daļu ķēžu, izmantoju ievērojami vairāk pārejas atveru nekā rūpīga manuāla trasēšana»). Tātad rezultāts stipri atkarīgs no konkrētās plates un no tā, cik labi izvietoti komponenti (placement) pirms palaišanas.
  • Появившиеся в 2026 году коммерческие AI-автотрассировщики (например, DeepPCB, Quilter) заявляют более высокое качество за счёт обучаемых моделей, но это платные облачные сервисы, а не бесплатный локальный инструмент, и для Pulsonix они напрямую не интегрированы (есть только плагины под отдельные программы, в основном KiCad).2026. gadā parādījušies komerciāli AI automātiskie trasētāji (piemēram, DeepPCB, Quilter) sola augstāku kvalitāti, pateicoties apmācāmiem modeļiem, bet tie ir maksas mākoņa servisi, nevis bezmaksas lokāls rīks, un Pulsonix tie nav tieši integrēti (ir tikai spraudņi atsevišķām programmām, galvenokārt KiCad).
Итоговая рекомендация для PulsonixNoslēguma ieteikums Pulsonix

Если лицензия Advanced Autorouter недоступна — для простых плат вполне достаточно встроенного Base Autorouter. Для платы, где хочется попробовать именно бесплатный сторонний автотрассировщик вроде FreeRouting, — сначала нужно уточнить у техподдержки Pulsonix (или проверить в меню File → Export / File → Import в своей версии), поддерживается ли вообще экспорт/импорт файлов Specctra DSN/SES без платной опции Specctra-линка — без этого связка с FreeRouting технически не соберётся, несмотря на теоретическую совместимость форматов.Ja Advanced Autorouter licence nav pieejama — vienkāršām platēm pilnīgi pietiek ar iebūvēto Base Autorouter. Platei, kurai gribas izmēģināt tieši bezmaksas trešās puses automātisko trasētāju, piemēram, FreeRouting, — vispirms jāprecizē Pulsonix tehniskajā atbalstā (vai pārbaudīt izvēlnē File → Export / File → Import savā versijā), vai vispār tiek atbalstīts Specctra DSN/SES failu eksports/imports bez maksas Specctra-linka opcijas — bez tā saikne ar FreeRouting tehniski nesastrādāsies, neskatoties uz teorētisko formātu saderību.
